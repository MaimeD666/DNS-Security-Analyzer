# Модель классификации

Обученного файла пока нет. Ответственный: Миша.

Предусмотрен многослойный персептрон по десяти числовым признакам, например MLPClassifier. Комплект должен сохранять преобразование признаков, модель, схему и порядок признаков, архитектуру, порог, random_state, версии библиотек, версию данных и контрольную сумму. Предсказание выполняется локально на CPU, обучение — отдельной командой.

Нельзя загружать произвольные сторонние сериализованные модели. Для проекта используются только файлы, полученные воспроизводимым обучением команды. Конкретные версии зависимостей и формат комплекта фиксируются при реализации.

Целевой файл `tunnel_model.joblib` пока отсутствует. Заглушку или случайные веса нельзя выдавать за обученную модель. Метрики до запуска испытаний не публикуются как полученные результаты.
