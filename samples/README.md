# Демонстрационные PCAP

Пока файлов трафика нет. На первой неделе Стёпа добавляет небольшой `sample.pcap` для вывода 3–5 DNS-пакетов и доменов. К стабильному MVP нужны:

| Файл | Назначение |
| --- | --- |
| `sample.pcap` | Первый разбор DNS-полей Scapy |
| `normal.pcap` | Нормальный трафик с известной статистикой и без предупреждений |
| `suspicious.pcap` | Синтетический пример для всех трёх правил |

Используем небольшие синтетические или публичные файлы. Для каждого добавленного PCAP указываем здесь автора/источник, условия использования для публичного файла, команду генерации при наличии и ожидаемые числа запросов, ответов и предупреждений.

Случайные дампы личного трафика не добавляем. `.gitignore` разрешает PCAP непосредственно в этой папке: перед коммитом проверяй содержимое и размер.

Пороги по умолчанию находятся в [config.json](../config.json). Если пример использует другие настройки, их нужно указать рядом с командой проверки.
