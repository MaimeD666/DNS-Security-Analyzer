# Учебные записи PCAP

Ответственный: Динда Степан. Генератор создаёт файлы на диске через dpkt без отправки пакетов в сеть. Каждый сеанс имеет идентификатор, SHA-256, параметры генерации и известную разметку.

| Сценарий | Назначение |
| --- | --- |
| normal | Обычные вопросы и ответы с проверяемой статистикой |
| normal_long_names | Обычная активность с длинными и уникальными поддоменами |
| tunnel_fast | Интенсивная передача через меняющиеся поддомены |
| tunnel_slow | 10–30 запросов за 300 секунд |
| no_dns | Корректный PCAP без пригодных DNS-запросов |

Записи сохраняются как Ethernet II, IPv4, UDP/53. Разметка по клиентам, доменам и времени описана в [data/README.md](../data/README.md). Разбиение формируется по исходным сеансам, а не по отдельным окнам. Личные дампы в набор не включаются.
