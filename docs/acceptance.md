# Порядок приёмки

Основание: раздел 12 [ТЗ версии 2.1](technical_specification.md).

## Функциональные проверки

| Код | Проверка |
| --- | --- |
| ПИ-01 | Установка и scripts/check_environment.py: PCAP, локальный PSL, обучение и загрузка персептрона |
| ПИ-02 | DNS-поля и статистика совпадают с ручным эталоном |
| ПИ-03 | Границы [start,end), разные клиенты и базовые домены |
| ПИ-04 | Десять признаков с абсолютной погрешностью не более 1e-6; >= для порогов |
| ПИ-05 | Минимум два условия и граница 9/10 запросов |
| ПИ-06 | Верные клиент и домен в hybrid для интенсивного и малочастотного сценариев |
| ПИ-07 | Объединение окон, уникальные пакеты и повторная загрузка модели |
| ПИ-08 | Консоль/TXT/JSON, ошибки, отсутствие данных, обязательность модели и запрет перезаписи |

Для каждого пункта протокол содержит команду, вход и его SHA-256, настройки, версию модели, ожидаемый и фактический результаты. ПИ-01 проверяет совместимость библиотек; алгоритмы анализатора проверяются отдельными пунктами.

## Оценка качества

Не менее 10 исходных сеансов каждого класса. Контрольная часть: не менее двух сеансов и 20 пригодных окон каждого класса. Train, validation и test разделяются по сеансам до формирования окон. Оба масштаба одного сеанса остаются в одной части. Домены синтетических туннелей test отличаются от train и validation. Дубликаты исходных записей исключаются.

StandardScaler обучается только на train. Порог модели и пороги правил подбираются по validation. Параметры фиксируются перед запуском test. Для трёх режимов вычисляются TP/FP/TN/FN, precision, recall, F1, FPR на одинаковых окнах. Результаты показываются отдельно для 60 и 300 секунд и совместно. Окна без достаточных данных или однозначной разметки исключаются с отдельным счётчиком.

Численные значения метрик, ошибки и сравнительный вывод включаются в отчёт. При нулевом знаменателе значение метрики обозначается как неопределённое. Метрики считаются на уровне окон; инциденты отражаются отдельно. Два масштаба одного сеанса не считаются независимыми исходными наблюдениями.

## Комплект и критерий

Проверки ПИ-01–ПИ-08 должны завершаться успешно на Linux x86-64 с CPython 3.12. Комплект содержит исходники, закреплённые зависимости, настройки, модель с метаданными, размеченные сеансы, реестр и разбиение, генератор, проверки, руководство, протокол и сравнительный отчёт. Все команды обучения, оценки и анализа приводятся в руководстве.
