# Комплект классификатора

Ответственный: Крутов Кирилл.

Модель: Pipeline из StandardScaler и MLPClassifier(hidden_layer_sizes=(16, 8), activation="relu", solver="lbfgs", max_iter=1000, random_state=42). Обучение и выбор порога выполняются отдельной командой. Начальный порог — 0.5.

Файл tunnel_model.joblib содержит конвейер и метаданные: порядок десяти признаков, параметры, порог, версии библиотек и идентификатор разбиения. Нормализатор обучается только на train. Порог выбирается по validation. Test используется для итогового сравнения трёх режимов. Сохранённая модель загружается в закреплённом окружении проекта.

Проверки: совпадение порядка признаков, исключение меток и имён из входа модели, конечные числовые значения, сохранение оценок после загрузки, обработка отсутствующего или несовместимого файла. Сериализованный файл загружается только из комплекта проекта.
