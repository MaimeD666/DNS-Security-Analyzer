# Демонстрационные записи

PCAP ещё не подготовлены. Ответственный: Стёпа. Сценарии формируются на диске без отправки пакетов в сеть. Для каждого файла нужен реестр происхождения, SHA-256, параметры и ожидаемые клиенты, домены и интервалы.

| Целевой файл | Содержание |
| --- | --- |
| `normal.pcap` | Обычные запросы и ответы с вручную проверяемой статистикой |
| `normal_long_names.pcap` | Обычная активность с длинными и уникальными именами для проверки ложных тревог |
| `tunnel_fast.pcap` | Интенсивный синтетический обмен через меняющиеся поддомены |
| `tunnel_slow.pcap` | 10–30 запросов за 300 секунд с известным клиентом и базовым доменом |
| `no_dns.pcap` | Корректная запись без пригодных DNS-запросов |
| публичный PCAP | Независимый пример туннелирования с источником и условиями использования |

Синтетическая строка в имени не доказывает реалистичность всех атак. Для обучения и контрольной оценки используются разные исходные сеансы и домены туннелей. Дополнительный публичный PCAP не используется для настройки. Крупные исходники не включаются в Git; приводится инструкция их получения.

Реестр: [data/manifest.json](../data/manifest.json), правила разметки: [data/README.md](../data/README.md). Целевые команды анализа указаны в README и заработают после реализации.
